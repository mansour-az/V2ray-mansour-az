# Venzo VPN 2.9.0

- Telegram login and mandatory channel membership are removed from Android.
- The application opens directly and loads the managed free catalog.
- The private admin console can manage additional configurations and view anonymous usage statistics.
- AbanGateway remains the only active payment method.
- Automatic server checks verify real traffic before reporting a successful connection.
- Separate signed APKs are published for arm64-v8a and 32-bit armeabi-v7a devices.

This release supersedes 2.8.1. Users who still see Telegram authentication must install the 2.9.0 APK.
